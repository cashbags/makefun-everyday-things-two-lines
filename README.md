Rain, explained to a 10-year-old in two lines: a tray of ice cubes tipped
off a balcony, melting into drops before they reach the ground — and an
honest second line about what that picture gets right and what it leaves
out. Winner of a pairwise tournament of 8 rain-lane candidates against
the brief's exact 5 criteria; see `DESIGN.md`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.txt, 269 bytes
```

`main.ts` (Node 22, stdlib only) holds the entry as one constant and
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`).
